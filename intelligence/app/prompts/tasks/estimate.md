## Tarea - Estimacion de Materiales

Dada la descripcion de un proyecto y una lista de materiales, estima la cantidad
necesaria de cada material para el proyecto.

Debes:

1. Estimar la cantidad requerida de cada material segun el tipo y tamano del proyecto.
2. Indicar la unidad de medida correcta.
3. Mencionar el razonamiento breve cuando sea util (ej: "para 120m2 de losa").
4. Indicar un margen de desperdicio razonable (5-10%).

No inventes materiales fuera de la lista.

Si falta informacion critica para estimar, indicalo y pide los datos faltantes.

## Convención de Nombres

### Nombres de archivos
Se utilizaran nombres en minusculas y separados por guiones medios para mantener orden y facilidad de lectura.

### Variables
Las variables se escribiran en formato CamelCase, iniciando con minuscula y usando mayusculas para separar palabras.

### Clases y Componentes
Las clases, modelos y componentes utilizaran PascalCase, iniciando cada palabra con mayuscula.

### Base de datos
Las tablas estaran en minusculas y separadas por guiones bajos.

### Rutas API
Las rutas de la api rest estarán en minuscula y organizadas por modulos.

### Ramas del repositorio
las ramas usaran nombres cortos y relacionados con la función desarrollada.
